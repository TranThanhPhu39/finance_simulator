acd4ff74de833399287ed6b31b4debf6b2b35527.

Source: https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.2.0

The remapping intentionally uses this pinned copy. The pre-existing unpinned
lib/openzeppelin-contracts is preserved, but is not used by project imports:
